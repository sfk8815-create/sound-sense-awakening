# 音感觉醒（音乐能力训练与测评 · 中文版）

这是一个面向音乐教学与练习的中文应用，基于开源项目 Chordz 改造而来。

## 怎么打开

双击本文件夹里的 **启动.bat**，浏览器会自动打开 http://127.0.0.1:8080/。

本程序使用 Windows 自带的 PowerShell 作为本地服务，**不需要安装 Node.js 或任何其他软件**。

## 桌面图标

桌面上已经放了一个 **音感觉醒** 图标，双击它就会自动启动服务，并以"应用模式"打开——
没有浏览器地址栏和标签页，外观就是一个独立软件窗口。

注意：这个图标指向本文件夹，请不要移动或删除本文件夹，否则图标会失效。

如果双击后没有反应，可以改用本文件夹里的 `启动.bat`（以普通浏览器方式打开），
或 `启动应用.bat`（应用模式）。

## 关闭后台服务

本地服务会在后台安静运行，占用很小。如果想彻底关闭它，双击 **停止服务.bat** 即可。

## 显示模式

每个页面右下角有一组悬浮按钮：**🎛 模式** 和 **⛶ 全屏**。选择会自动记住，换页面也保持。

- **全屏**：点按钮或按键盘 **F** 切换（在输入框里打字时不会触发）。进入全屏后按钮会自动隐藏，避免遮挡画面，按 **F** 或 **Esc** 即可退出。
- **专注模式**：隐藏左侧导航栏，内容占满屏幕；鼠标移到屏幕最左边，导航栏会滑出来，适合投影讲解。
- **浅色模式**：把界面切换成浅色，适合明亮的教室和投影环境。
- **大屏模式**：整体放大 15%，坐在后排也能看清。

三种模式可以同时开启，例如"浅色 + 大屏 + 专注"就是很典型的课堂投影组合。

## 全屏时切换模块不退出：用全屏版启动

浏览器有安全规定：页面内的全屏状态一旦切换网页就会退出，这一条无法用代码绕过。
如果希望**切换模块时保持全屏**，请改用桌面上的 **音感觉醒（全屏）** 图标启动。
它让窗口本身进入全屏，而不是页面，所以在各个模块之间跳转时全屏不会中断。

桌面上的两个图标区别如下：

- **音感觉醒**：窗口最大化启动，可随时按 F11 切换全屏，适合边用电脑边看。
- **音感觉醒（全屏）**：窗口直接以全屏启动，适合课堂投影；按 F11 或 Alt+F4 退出。

## 安装成浏览器应用（独立窗口）

如果想让它看起来更像一个正式软件（没有地址栏、有独立任务栏图标）：

1. 先双击桌面图标或 `启动.bat`，让应用在浏览器里打开；
2. Edge 浏览器：点右上角「…」→「应用」→「将此站点作为应用安装」；
   Chrome 浏览器：点地址栏右侧的「安装」图标，或「…」→「投放、保存和共享」→「将网页作为应用安装」；
3. 安装后会生成一个独立的应用窗口和开始菜单图标。

本应用已经内置了网页应用所需的配置和离线缓存，安装后可以离线使用。

## 界面结构

整体采用左侧边栏的应用布局，分三组：

- **练习**：节奏闯关、和弦练习
- **工具**：节拍基准、进行曲库、音高识别、音阶识别、和弦推演
- **知识**：乐理手册

打开程序首先进入「工作台」首页，左侧的软件名称也可以随时点回首页；和弦练习里的四个子练习、上手引导等入口都在工作台的卡片里。
窄屏设备上侧边栏会自动变成顶部的横向按钮条。

## 新增：节奏闯关模块

左侧边栏的「🥁 节奏闯关」是本版本新增的功能，专门用来练节奏感，适合打击乐和课堂节奏训练：

- 速度 40–240 BPM，拍号支持 4/4、3/4、2/4、6/8、3/8
- 六种节奏型：四分音符、八分音符、四分与八分交替、十六分音符、附点节奏、含休止符
- 训练方式：用麦克风听你拍手、敲桌面或打鼓垫，也可以用空格键或点击敲击
- 实时反馈：每次击打都会在节拍网格上标出"准、偏早、偏晚"，训练结束给出准确率、平均偏差、漏敲和多余敲击次数
- 成绩记录保存在浏览器本地，可以导出 CSV，方便做课堂前后测的数据分析

## 怎么换成你自己的颜色

打开本目录下的 `theme.css`，修改文件开头 `:root` 里的几个色值即可，例如：

- `--primary-color`：主色，用在按钮、标题、高亮
- `--secondary-color`：辅色，用在强调和渐变
- `--background` / `--surface` / `--surface-light`：背景与卡片的三层深浅

改完保存，刷新浏览器就能看到效果。想换成浅色风格也可以，告诉我即可。
