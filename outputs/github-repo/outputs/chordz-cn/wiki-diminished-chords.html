减和弦

听起来紧张，负责把音乐推回主和弦

结构

减和弦由根音、小三度与减五度组成，音程是两个小三度叠置，符号是 °。

示例：B 减和弦：B-D-F（B→D 三个半音，D→F 三个半音）

出现在哪里

  • 大调音阶的第七级，例如 C 大调中的 Bdim（vii°）。
  • 自然小调音阶的第二级，例如 a 小调中的 Bdim（ii°）。

怎么用

减和弦有强烈的倾向性，常放在主和弦前面作为过渡，形成 vii° → I 的进行。

在流行与爵士中，它也常作为经过和弦，让低音线条更连贯。
