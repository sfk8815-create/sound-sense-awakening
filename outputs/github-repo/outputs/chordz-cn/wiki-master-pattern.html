核心音程模式

全全半全全全半，这一条串起了音阶、和弦与调性

先认识全音与半音

半音是音与音之间最小的距离，钢琴上相邻的两个键（包括黑键）就是一个半音，例如 E 到 F、B 到 C、C 到 C#。

两个半音合起来是一个全音，例如 C 到 D、D 到 E。

大调音阶的模式

从任意一个音出发，按“全 全 半 全 全 全 半”的顺序往上走，得到的就是大调音阶。

示例：C 大调：C → D → E → F → G → A → B → C（E-F 与 B-C 之间是半音，其余是全音）

换一个主音试试

这就是为什么不同的调会有不同数量的升号或降号。

示例：G 大调：G → A → B → C → D → E → F# → G（为了满足模式，第七个音要升高半音）

为什么它重要

  • 所有大调音阶都由它推导出来，调号也由此确定。
  • 大调中的七个自然和弦（I ii iii IV V vi vii°）来自这条音阶。
  • 理解了模式，就不需要死记每个调的音，可以随时推算。
