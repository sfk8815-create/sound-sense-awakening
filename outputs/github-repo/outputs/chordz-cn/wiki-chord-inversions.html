和弦转位

同一个和弦，换一个低音，连接就更顺

三种位置

三种位置用到的音完全相同，只是排列顺序不同，因此听起来功能相同、色彩略有差别。

  • 原位：根音在最低处，例如 C-E-G。
  • 第一转位：三音在最低处，例如 E-G-C。
  • 第二转位：五音在最低处，例如 G-C-E。

为什么要用转位

  • 让低音线条更平滑，避免大幅跳跃。
  • 伴奏时减少手部移动，弹奏更轻松。
  • 为旋律让步，让内声部更自然。

如何判断转位

看最低音是哪一个：最低音是根音就是原位，是三音就是第一转位，是五音就是第二转位。

示例：C 和弦：C 在最低 → 原位；E 在最低 → 第一转位；G 在最低 → 第二转位

练习方法

在“和弦练习”里打开“转位闯关”，选择一个和弦，按提示依次弹出原位、第一转位与第二转位，程序会记录用时并给出最佳成绩。
