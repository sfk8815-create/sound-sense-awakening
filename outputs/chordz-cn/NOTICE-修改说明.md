# 修改说明

本目录基于以下开源项目修改：

- 项目名称：Chordz
- 作者：mymindwentblvnk
- 原仓库：https://github.com/mymindwentblvnk/chordz
- 许可证：MIT

修改内容：

1. 界面文本中文化：导航栏、训练模块、节拍器、和弦选择列表、页面标题。
2. 将声音引擎 Tone.js 从 jsDelivr CDN 改为本地文件 `vendor/Tone.js`，实现离线可用。
3. 增加本地服务器脚本 `server.js` 与启动脚本 `启动.bat`。
4. 增加中文使用说明。
5. 品牌改版：应用更名为“音感觉醒”，新增 `theme.css` 自定义主题层，替换配色与导航样式。
6. 新增“节奏训练”模块（`rhythm-training.html`），为原项目所没有的原创功能。

原项目的 MIT 许可证全文见本目录下的 `LICENSE` 文件。
