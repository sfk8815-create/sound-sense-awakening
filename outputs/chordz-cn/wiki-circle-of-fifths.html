五度圈

把十二个调排成一个圆，调号与关系调一眼看清

怎么排的

从 C 出发，每次向上走纯五度，就得到升号方向的调；向下走纯五度，则得到降号方向的调。

示例：升号方向：C → G → D → A → E → B → F#；降号方向：C → F → Bb → Eb → Ab → Db → Gb

升号与降号的顺序

  • 升号顺序：F# → C# → G# → D# → A# → E# → B#
  • 降号顺序：Bb → Eb → Ab → Db → Gb → Cb → Fb
  • 调号里出现几个升号，就按顺序取前几个。

关系小调

每个大调都有一个关系小调，它们使用相同的音与调号。小调主音就在大调主音的下方小三度，例如 C 大调与 a 小调。

有什么用

  • 快速判断调号，不用逐个音去数。
  • 理解和弦进行中为什么会用到某些和弦。
  • 转调时，找相邻的调最容易自然衔接。
